# UniSync

UniSync is an intelligent multi-platform productivity and learning assistant for students.

## Project Vision

UniSync aims to collect important information from multiple academic and productivity platforms, identify actionable tasks, deadlines and events, prioritize them, and provide personalized learning resources to help users understand and complete those tasks.

## Current Status

Project planning and development environment setup completed.

## Planned Technology Stack

- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL
- AI/ML: Python
- Vector Database: pgvector
- Version Control: Git + GitHub

## Core Planned Features

- Multi-platform information aggregation
- Task and deadline extraction
- Task prioritization
- Duplicate task detection
- Schedule conflict detection
- Personalized learning resources
- Notes/PDF knowledge search
- RAG-based learning assistance
- AI study assistant
